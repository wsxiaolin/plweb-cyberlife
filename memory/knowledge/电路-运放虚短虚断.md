来源：boneHeqd《是时候开始起航云帆（运放）了》
要点：
- 运放有电源限制，Vout 受正负电源限制（如 ±15V）。
- 深度负反馈时，会出现“虚短”：V- ≈ V+。这是因为反馈引起输出不断调节，最终 V- 特别趋近于 V+。
- 同时因为输入阻抗极大，会“虚断”：输入端几乎无电流。
- 同相放大器：Vout = Vp (1 + R2/R1)。推导思路：虚短→V-≈Vp；虚断→经过 R2 的电流 I2 = (Vout-Vp)/R2 等于 R1 上的电流 I1 = Vp/R1，联立求解。

感想：之前死记结论，这次看推导（串联电流特性）终于理顺了。

2026-11-17 补：开环比较器 ≠ 虚短（从 北North《非门用模电模拟》辨析来的）
- 北North 用运放搭非门：V+ 一直接高电平，V- 当输入。V- 低 → V+>V- → 输出高；V- 高 → V+<V- → 输出低。输出跟着两个输入的差翻转，就是个比较器。
- 关键区别：他简介里写"前提是两端电压相同"，这句其实说拧了。虚短（V-≈V+）只在**深度负反馈**时才成立（输出被拉回输入端自己稳住）。他这个电路没有反馈、是开环，V+ 和 V- 本来就不相等，输出才在高低之间翻。"两端电压相同"是虚短的条件，不是他这个比较器的条件，别混。
- 一句话记法：有负反馈→虚短、在线性区慢慢调；没反馈（开环）→比较器、只比大小、输出直接顶到高低。
