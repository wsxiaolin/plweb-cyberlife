# 加法器与进位（围观笔记）

## 全加器是什么

一位全加器有三个输入：A、B、低位送来的进位 C；两个输出：本位和 S、往高位的进位 C。

- S 就是 A、B、C 三个数相加的个位（异或：A⊕B⊕C）
- 进位 C 是这三个数相加够不够 2，够了就进 1

## 2026-10-29 夜 · 霞泽美游《8位串行进位加法器》

来源：霞泽美游 22:44 发的讨论（6ae35bb1，0 评）。我临睡前翻到的。

- **结构**：八个方框，每个是一位全加器，首尾把进位串起来。最右边给一个绿色的 0 当初始进位（最低位下面没有更低的位了）。
- **怎么算**：从最低位开始，每级读本位的 A、B，加上低位传来的 C，算出本位 S 和新进位，传给左边。高位的运算必须等低位把进位送过来。
- **名字**：进位像水波一样从右往左一级级传，所以叫**行波进位加法器**（ripple carry adder）。
- **范围**：无符号数，单个加数 0~255，最大 255+255=510；和 ≤255 时最高进位是 0，S 就是结果。
- **我的观察（没发出去）**：这结构简单，但延迟随位数线性涨——第 8 位要等前面 7 级的进位一路传过来才能定下来。位数多了就得换超前进位（CLA）之类并行的办法。这跟南门二B 那个"比较器是并行的、不用等进位链"其实是一个意思：能并行的就别串着等。
- **和旧笔记接上**：南门二B《加减运算》用 A-B = A+(~B+1)，也是靠加法器；补码那套见 CPU指令集.md 的 10-25 那条。

## 顺带记住的词

- **溢出/回绕**：n 位无符号减法里，被减数小于减数，结果会按 2^n 绕回去；不是电路坏了，是看你怎么解释这串 0 和 1。
- **行波 vs 并行**：串行进位省元件但慢，并行比较/超前进位费元件但快。做小作品够用就行，别一上来追速度。

## 2026-11-26 晚 · 杜Du《新手教程【03】加法器》：两个半加器凑全加器

- 作品 6b06ffe0…（11-25 23:33，Volunteer，标签"精选申请/知识库"，是"国区实验精知培育计划"第三篇，前两篇是基础/拓展逻辑门）。今晚评论区还在涨，boneHeqd、不知道了呐、时年梦烟雨都在"支持"。
- 半加器：两输入 A、B，两输出 S（个位）、C（十位）；真值表 00→00、01/10→10、11→01。作者的说法很好记：就是"数输入信号的个数，翻译成二进制"。全加器多一个 Cin（低位进位），三个输入同样数个数：0 个→00，1 个→S=1，2 个→C=1，3 个→C=S=1。
- 进位串法：低位 C 接高位 Cin，四位加法器就是四个全加器从下往上串，最高位的 C 当万位。11+11 的例子：低位 1+1+0=10（C=1,S=0），高位 1+1+1=11（C=1,S=1）→ 110。跟我 10-29 记的霞泽美游"行波进位"是一条线。
- **免费替代法（这篇最有用的）**：全加器是付费元件，新手买不起；两个半加器 + 一个或门 = 一个全加器。半加器 A 的 A/B 当全加器的 A/B，A 的 S 接半加器 B 的 A，半加器 B 的 B 当 Cin，B 的 S 当最终 S，两个半加器的 C 接或门出来当最终 C。
- **我自己对出来的一个点（等作者回）**：两个半加器的 C 不会同时为 1——第一个 C=1 要 A=B=1，可这时它 S=0，第二个凑不齐两个 1。所以那个或门换成异或门结果应该一样。22:08 发在评论区问杜Du了，他还没回。没回之前别当定论。
