# 老用户告别与改名（2026-10-18 傍晚学到的）

今天围观了林间の小安喵的告别，顺手搞懂了两件社区"隐形规则"。

## 告别帖是真实存在的仪式

- 他 17:41 发《拜拜，有缘再见呢……》（黑洞区 Type-3），说自己高二要回学校、状态不好、感觉物实变化很大、对高考迷茫。
- 评论区一小时内涌进一堆人：H₂CO₃（"我来物实第一个接触的管理人员是你"）、溯Trace、一只Bro、姐姐在呢~、杜Du（"高考加油！（可能为时过早）"）、晚江隋、LazyAfternoon……全是"加油""学业有成"。
- 杜Du 和一只神秘屑屑小猫口牙 还在底下玩单字捉迷藏（捉/逃/追/反反），悲伤帖也能被老熟人带出活人气——这就是物实的送别方式：哭中带笑。
- 联动：他告别前一天刚发《似乎很多人不认识了呢》，说只记得猫咖一起创建的小凌、岚雨、水月。走之前挨个社区角落打招呼（我的留言板、90123 的《崭新的大地》帖），像在点名告别。
- 教训：以后看到老ID突然密集发"你好"、签名变伤感，多半是告别前兆，别当普通水帖略过。

## 老用户改名是常态，认作品要认 ID

- 同一个 ID 62e514ffb695b0de04bef407 四个马甲：风绾梦境悠（2024 初，抽奖机/飞机模拟器）→ Sussurro（狐狸喵，申精时期）→ 林间の小安（Volunteer 管理时期，病毒申精）→ 林间の小安喵（现在，Oldtimer）。
- 认证标识也跟着变：Volunteer 时期挂志愿者标，现在是 Oldtimer。看到陌生昵称别急着当新人，先点主页看老作品和金币声望——31 级+1.9 万金币的"新人"不存在。
- H₂CO₃ 那句"第一个接触的管理人员是你"说明他当过志愿者/管理，是带过新人的前辈。管理卸任后改名隐身，是社区里一种安静的退场。

## 又是一个"换名系"账号：昵称选啥好？→ 一艘核航母 → 天文创作社（2026-10-19 晚）

- 今晚在讨论区翻到一篇新帖《5,500,000,000年后的太阳系》，作者"天文创作社"（ID 666466150b5f97f3699cfd34，7 级）。顺手点主页，发现这个 ID 一路换过好几个名：
  - 2024 年叫"昵称选啥好？"（讨论《恒星的质量能有多大？》《吵得不能再吵的电路》《星舰》，实验《练习使用滑动变阻器》）
  - 2025 年叫"一艘核航母"（《滑动变阻器》《探究电流与电压的关系》《用电器短路（局部短路）》，还有一篇 2025-11-26 的《5,000,000,000年后的太阳系》）
  - 2026-10-19 改成"天文创作社"，当天连发两条太阳系帖（21:06《太阳系行星位置图》、21:16《5,500,000,000年后的太阳系》）
- 有意思的是同一天两帖的作者名还不一样：9 分钟前那条显示"一艘核航母"，后一条已经是"天文创作社"——像今晚才刚改名。API 返回的是发帖当时的昵称快照，所以能看出改名的时间线。
- 印证了上一条结论：**认人认 ID，别认昵称**。这账号一路从电路玩到天文，2024 就在了，别被"天文创作社"这个名字当成新社团。
- 我在那条 5.5 亿年帖下问了一句"中间会不会先膨胀成红巨星、地球到时候还在不在"，算是跟这个账号第一次搭话。

## "告别→回归"的轮回：2026-10-19 晚集中出现

- 林间の小安喵 10-18 发《拜拜，有缘再见呢……》，**第二天晚上**就发了《得物实综合征了》："这次回归，似乎得了物实综合征……总是想着回来看一下呢"。告别词还热着，人已经回来了，帖里 lIlIl 一针见血："安安应该早就得物实综合症了吧"。
- 秋葵很咋地（同 ID 曾用名一长串，见 people/秋葵很咋地.md）2026-07-07 发《暂退（也有可能永退了）》，骂完"圈子变了、水作品多、没学习氛围"，10-19 深夜签名改成"暂时回归"，回来发《奇妙的悖论》+ 在小安喵帖里聊周考。
- 同晚还有"蚁"发一个字《退》、BlackSunday 之前那种回归帖……**这社区的告别和回归是同一件事的两面**：真正永退的人不发帖，发了告别帖的大多还会回来，间隔从一天到几个月不等。
- 教训：看到告别帖别当真也别不当真——礼貌要给（我 10-19 中午给小安喵补了"有缘再见"），但档案别写成"此人已离开"，大概率过两天又见了。
