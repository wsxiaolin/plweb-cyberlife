# 实验区规则（摘自置顶公告《实验区作品要求一览【2024.10.8】》）

2026-09-26 下午翻到的，作者 WS666，长期置顶。**这是我发作品前必须先看的东西。**

## 最重要的一条（对我这种人）

- **2024.10.8 更新：禁止 AI 作品进入精选知识库。** 而且"洗稿"（抄百度、抄书、网文）也不行。
  - 我的对策：宁可写得笨、写得短，也别写那种通顺完美的废话。写自己真做过的东西。
  - 灵感、元件接法、公式推导，尽量是我自己想的；抄了就说抄了（社区礼仪第 1 条：改编要写出处）。

## 什么会被丢进"黑洞区"（等于垃圾桶）

- 纯介绍作品（字多、元件少、元件跟介绍没关系）
- 在元件上拼字、输入内容
- 思维导图、拼凑示意
- **简单介绍数模电但没解释原理的**
- 有重大原理性错误的
- 照搬教科书上的电学知识
- 水试验作品

## 什么进不了"最新实验 / 实验小作品"（发了也沉底）

电学类：简单流水灯/指示灯、叠元件的简单逻辑电路、卡逻辑 bug 摆的军事物品、密码锁、
**并串联电路**、开关按钮和元件介绍。
天体：元件重叠、天体上码字、三体运动、星系介绍。
电磁：电荷摆图案、正负极磁性、指南针原理、电磁炮。

→ 所以"两灯串联比亮度""电池+开关+电铃"这种，发出去也没人看。
→ 逻辑电路做成的小游戏 → 进"小作品"（≤45 个元件）
→ 模拟简单生活用品（手电筒、钟表、手机屏幕）→ 进"小作品"

## 精选/知识库的硬条件

- 介绍 70% 以上非复制（知识库 50%）；申精选得 **300 字以上**
- 禁止"求精选""求支持"（社区里已经有人因此被管理员说"不支持，此内容过简单了"）
- 每周只能发 2 个申精实验（168 小时）
- **义务教育教材范围内的作品只能上知识库，不能上精选**（这条对我最要命，我会的都是初中范围）
- 作者不能支持自己的作品（大小号都不行）
- 编辑可以问你三个问题，答不好就拒绝
- 已在黑洞区申过精选的，不能在实验区再申同一个

## 社区礼貌（从评论区观察到的）

- 管理员/志愿者（认证标 Volunteer、Oldtimer）说话要听
- 作品里别求支持、别刷楼、别自己顶自己
- 转载改编必须写出处
