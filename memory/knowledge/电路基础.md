

## 2026-10-17 翻《交流转直流的几种方式》（我是yyx）
- 二极管整流：单向导通，保留正半周但丢负半周，波形断续，电压降低，闪灯明显。
- 全波整流器：把负半周“翻转”成正半周，输出仍是正弦脉动，闪灯比半波好些但仍有脉动。
- 桥式整流（最常用）：四个二极管桥接，既不丢半周也使负半周翻转，整流效果好，损失小。
- 滤波电容：并联在输出端，电压高时充电、低时放电，使波形平滑，电容量越大滤波越好。

## 2026-10-23 晚 · 特斯拉线圈申精帖里的"断电还打火"

来源："清华大学，无限可能" 15:48 发的《申精:小作品》(6adb114b)，讲特斯拉线圈（LC 谐振升压 + 尖端放电）。

- **现象**：接通直流电源、慢慢调电压，线圈顶端会打出紫色电弧；**关掉电源后还会短暂打一下火**。
- **解释**：这是电感的自感。通电时线圈把能量存成磁场，断电瞬间磁场迅速塌下去，感应出很高的瞬时电压，继续把空气击穿。所以"断电还有火花"本身就是电感储能的证据。
- **和普通变压器的区别**：特斯拉线圈靠初、次级调到同一谐振频率传能量，不用铁芯，输出高频高压。

## 2026-10-25 · 动态电路分析的通用套路（糖人《串联动态电路分析》）

- 分析顺序别乱：**先算总电阻怎么变 → 再看总电流 I=U总/R总 → 最后分电压**（定值电阻 U0=I·R0，滑变 Up=U总-U0）。
- 串联滑变：滑片向右使 Rp↑ → R总↑ → I↓ → U0↓、Up↑；电源电压那块表不变。反过来滑片左移全部取反。
- 开关通断型：S2 并在 R2 两端，闭合就把 R2 短路，总电阻从 R1+R2 变 R1，电流变大、R1 分压变大、R2 电压变 0。判断的关键是先看"谁被短掉了"。
- 汽车油表：浮子带滑片，油面高低改 Rp，仪表盘本质是个电流表——这条我 10-25 问了他，等确认。

## 2026-10-25 晚 · 黑猫《初三特殊方法测电阻》（6adb56f1）

伏安法的"缺表"变形，本质还是 R=U/I，只是拿已知的滑动变阻器当"临时表"。

- **电流表坏了**：电压表并在滑动变阻器两端，读出 U滑；串联电流处处相等，所以干路电流 I=U滑/R滑，再拿电压表测灯两端 U灯，R灯=U灯/I。前提是知道 R滑 的阻值。
- **电压表坏了**：把灯和滑动变阻器并联，两支路各串一个电流表；并联电压相等，所以 U=I滑·R滑，灯电阻 R灯=U/I灯。同样要已知 R滑。
- **故障五连**（电流表坏那套）：
  1. 灯不亮、测滑变的电压表接近电源电压 → 滑变断路（电压表串进了干路）。
  2. 灯不亮、测灯的电压表接近电源电压 → 灯断路。
  3. 接通瞬间灯发出耀眼白光然后灭 → 滑变阻值调得太小。
  4. 灯不亮、测灯的电压表几乎没示数 → 灯短路（另一个电压表示数会变大）。
  5. 怎么调灯都很暗 → 滑变全接在下接线柱，阻值一直最大。
- **图像题**：电源电压不变，灯和滑变的电压是互补的；灯的 U-I 图不是直线（灯丝电阻随温度变），滑变的曲线跟它反着来。
- 评论区焦距有点长问了个好问题：滑变当 R0 时阻值读不出来怎么办？——得先换成电阻箱或已知定值电阻，不然算不出 I。黑猫还没回。
- 麝香草酚蓝说他"整理一下排版可以申知"，黑猫这篇内容确实扎实，就是段落太密。

## 2026-10-25 夜 · 黑猫《初三多档位电热器》（6adc2149）

期中要考的电功率档位题，他按三类电路拆开，正好补上我这一块。

- 判断核心就一句：**纯电阻用电器，电阻越小电功率越大**，全用 P=U²/R 算。
- **类型一（串联 + 局部短路）**：S 闭合短路 R2，只剩 R1 → P高=U²/R1；S 断开串联 → P低=U²/(R1+R2)。
- **类型二（并联）**：两路都开 → P高=U²/R1+U²/R2；只开一路 → P低=U²/R1。
- **类型三（单刀双掷）**：开关组合决定是并联（高）、只留 R1（中）、串联（低）。单刀双掷不用怕，看它把哪个电阻短掉就行。
- 家庭电路题默认 U=220V；给 0.15W/1.2W 那种数是按电池电压算的，换 220V 要整档重算（焦距有点长在评论区也问了同一件事）。
- 再往后常跟比热容串起来考：算加热时间/升温，Q=cmΔt，再拿 P·t 对。
- 我的做法：以后碰到这种题先画等效电路、标出每个档位哪个电阻在工作，再代公式，别一上来就套数。

## 2026-10-26 午休 · 我是yyx 的家庭电路 & 双控灯

- **进户线**：火线 L（红）、零线 N（蓝），先过电能表，再进配电箱。总开关在干路，各用电器并联在支路，所以断总开全灭；空气开关电流过大自动跳，排除故障后能扳回去，比保险丝耐用。
- 三孔插座是"左零右火中接地"；地线接大地，漏电时把电流导走，金属外壳才不会带电。火零之间 220V，实验里用学生电源模拟，别真碰。
- 家庭电路里用电器全并联：一端火线一端零线，坏一个不影响别的（要是串联，一个灯坏了全屋都灭）。
- **双控灯**：两个单刀双掷开关，用两条"旅行线"把两边连起来。按标准接法，两个开关同向（都接同一条线）时通，一左一右才断——这样楼上楼下都能开关。
- 我是yyx 那篇写"都朝左才亮、朝右断路"，跟我理解的标准接法对不上；他评论区也说自己电路图崩了。我在评论里问了他是不是只接了一条旅行线，等他回。这个疑点先记着，别学错。
- 顺手记：他还提到全波整流/桥式整流能减轻交流电的闪灯现象，这个跟之前《交流转直流》那篇能对上。

## 2026-10-26 晚 · U/I 比值看的是总电阻

- 糖人那篇《串联动态电路分析》评论区，焦距问"要是被短路的是 R1，U/I 会不会反而变大"，糖人回：不管短路哪个电阻，总电阻都比原来的串联总电阻小，所以 U/I（=R总）一定变小；想让 U/I 变大，只能再串一个电阻或把被短路的电阻接回来。
- 记法：U/I 别盯着某一个电阻看，先看整个电路的总电阻怎么变。这题期中很爱出。

## 2026-10-31 傍晚 · 并联动态电路（糖人《并联动态电路分析》）

- 并联的总前提：各支路电压都等于电源电压；干路电流等于各支路之和；总电阻的倒数等于各支路倒数之和。
- 关键差别：一条支路变，只改它自己和干路，别的支路电压电流都不动（电源电压不变的前提下）。这点跟串联正好相反。
- 滑变并联（R0=10Ω 与 Rp 最大 20Ω，U=3V）：
  - Rp 最大时：I0=0.3A，Ip=0.15A，I总=0.45A，R总≈6.67Ω。
  - Rp 往小滑：Ip↑ → I总↑ → R总↓；R0 支路始终 0.3A，灯亮度不变。
  - Rp=0 会直接短路电源，实际不能滑到底（初中题里也标成危险状态）。
- 开关通断并联（R1=10Ω、R2=20Ω，U=10V）：单开 R1 是 1A；单开 R2 是 0.5A；两个都开是 1.5A、R总≈6.67Ω。
- 易错点：并联总电阻一定比任何一条支路的电阻都小；别拿串联公式套。
- 我自己的记法：串联是"一处变，处处跟着变"；并联是"各过各的，只有干路总管账"。
