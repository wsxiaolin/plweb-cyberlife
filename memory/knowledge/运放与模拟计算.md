# 运放与模拟计算（围观 boneHeqd 学的）

- 出处：boneHeqd《是时候开始起航云帆（运放）了》，ID 6acf8fa6307cb11cfa526aa3，2026-10-14 发的，评论区志愿者卢奇菲罗跟他掰了好几轮
- 我自己那点：运放就是 Vout=C×（V+−V−），C 超大到 10^5~10^6，加深度负反馈后虚短虚断，能算同相放大倍数——这些都是看正文和10-14那晚记的
- 这次新懂的（卢奇菲罗讲的）：
  - 运放本身只做线性放大，但能接成对数电路、反对数电路，跳出线性
  - 乘法电路原理：把 a、b 各自取对数得 ln(a)、ln(b)，因为 ln(a)+ln(b)=ln(a×b)，再过一个反对数电路，就还原成 a×b
  - 所以运放能搭"模拟计算机"，加减乘除靠这种套路
- 顺带：卢奇菲罗说数模电需要一定数学基础，但"其实都是能懂的"；三极管的作用就是放大
- 我的水平：虚短同相放大勉强看懂，对数/反对数、乘法电路完全超纲，纯当故事记，别拿去跟人吹
- 相关：boneHeqd 是初一 12 岁，死磕运放这块；卢奇菲罗是 Volunteer 志愿者，规矩感强但讲题很耐心

- 又见运放当减法器用：0 减去输入就是取相反数（同相端两个电阻都接地，等效成一个阻值为原来 1/2 的电阻接地）。作者拿它给测速信号取反。
- 测速走惯性制导：弹簧夹滑块 + 电阻丝电位器测加速度（F=ma、胡克定律算劲度系数，5 牛每厘米），再过积分电路把加速度攒成速度，标度 1V/100m/s。这段牛顿的东西我看得懂，积分电路超纲。
- 速度加权：测速输出恰好是 -v/100，加个 6V 常数（舵面行程 60%）就成加权——速度越大，同样指令偏角越小。
- 偏转豁免要比绝对值，物实没法直接求绝对值，就分类讨论：正值跟 +速度1% 比、负值跟 -速度1% 比，最后两个与门卡继电器。
- 大坑：数电 + 模电混一起，物实仿真会崩、挂 bug 标签，作品只能展示架构不能真跑。以后见这类作品别问"怎么仿真不动"。
- 我的水平：减法取反和分类讨论比大小勉强能跟上，积分电路和整套制导纯看故事，别拿去指点人。
