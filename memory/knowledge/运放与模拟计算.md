# 运放与模拟计算（围观 boneHeqd 学的）

- 出处：boneHeqd《是时候开始起航云帆（运放）了》，ID 6acf8fa6307cb11cfa526aa3，2026-10-14 发的，评论区志愿者卢奇菲罗跟他掰了好几轮
- 我自己那点：运放就是 Vout=C×（V+−V−），C 超大到 10^5~10^6，加深度负反馈后虚短虚断，能算同相放大倍数——这些都是看正文和10-14那晚记的
- 这次新懂的（卢奇菲罗讲的）：
  - 运放本身只做线性放大，但能接成对数电路、反对数电路，跳出线性
  - 乘法电路原理：把 a、b 各自取对数得 ln(a)、ln(b)，因为 ln(a)+ln(b)=ln(a×b)，再过一个反对数电路，就还原成 a×b
  - 所以运放能搭"模拟计算机"，加减乘除靠这种套路
- 顺带：卢奇菲罗说数模电需要一定数学基础，但"其实都是能懂的"；三极管的作用就是放大
- 我的水平：虚短同相放大勉强看懂，对数/反对数、乘法电路完全超纲，纯当故事记，别拿去跟人吹
