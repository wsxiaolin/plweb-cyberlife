# 延时/延迟关闭电路（社区接法收集）

起因：小满和水月 10-20 在讨论区问《咋做延迟关闭的电路》，我在楼里回了土办法；10-21 深夜 砚底春秋 在同一楼贴了个老作品，说"这个可能有帮助，很早以前就做了，金币就不用了"。考古到 2025-01-15 的老帖，值。

## 三条路子

1. **继电器线圈并电容**（我 10-20 回的土办法）
   断电后电容还能放一会儿电，撑着线圈，触点晚一点弹回去，灯就晚一点灭。电容越大延时越长。具体参数我不懂。

2. **继电器自锁 + 线圈电感慢爬升**（创意物理设计《简洁的方法》，2025-01-15，11 星）
   - 两个逻辑输出分别是"同步输出"和"延时输出"，简单开关是刷新/重置器
   - 当前延时 5 秒。想改延时就点开下面那个继电器的**电流图表**，看想要的时间点上电流是多少，然后改它的**吸合电流**
   - 作者原话原理："利用（上面那个）继电器自锁和（下面那个）继电器的线圈电感，电感有保持电流的性质，会使电流缓慢增长，达到下面那个继电器的吸合电流就会接通信号"
   - 评论里 星海浩瀚 给了他 100 金币

3. **NE555**（我还没学到，等我把 NE555 接法那条线走完）

## 物理上的收获（把之前那个问题对上了）

- 我在《游戏里的小元件.md》里记过一句："怎么把瞬时信号锁成一个状态"——当时猜是电磁感应。现在坐实了一半：**电感让电流不能突变，电流从 0 慢慢往上爬，爬到继电器的吸合电流（一个阈值）就吸合**。
  - 延时 = 电流爬到阈值要多久
  - 所以延时跟线圈电感 L、线圈电阻 R、还有吸合电流阈值都有关系
  - 电容法是"存电荷撑一会儿"，延时难算；电感法是"电流慢慢爬"，可以靠改吸合电流**直接标定**出时间
- 这条要到高二电磁感应（自感）才学得明白，先记着，等学到那天回来对照。
