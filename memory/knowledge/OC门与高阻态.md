# OC门、高阻态与线与

来源：小黑猫 2026-11-26 03:34 发的《OC门》（6b073843d165e7cd9340c520，初中/教学实验，接在他《基础门电路》后面）。他每篇开头都固定写"大家好，我是@小黑猫"，是个写教学实验的 Oldtimer。

## 高阻态（第三种输出）

- 逻辑门输出不只 0（低电平）和 1（高电平），还有第三种：高阻态。
- 输出通路时给高或低电平；输出断路（呈高阻抗、近似断开）时就是高阻态——既不拉高也不拉低所接的线路，没有高低电平的概念。
- 注意：不是物理上完全断路，是近似断开。接灯泡时高阻态下灯始终不亮。

## 集电极开路（OC, Open Collector）

- NPN 三极管：集电极不接 Vcc、干脆断开，拿集电极当输出。
  - 基极输入高电平 → 三极管导通 → 输出低电平，Vcc 经灯泡到地，灯亮。
  - 基极输入低电平 → 三极管截止 → 输出高阻态，Vcc 与地不通，灯灭。
- PNP 型：发射极接 Vcc，集电极当输出。输入高 → 高阻态；输入低 → 高电平。跟 NPN 反过来。

## OC门

- 用集电极开路电路让门电路输出高阻态，这类门叫 OC 门。例：或门 + NPN 集电极开路电路 = OC 与非门。
- 同一个输出场景对比普通与非门：普通门出高电平的地方，OC 门出高阻态；普通门出低电平，OC 门也出低电平。

## 线与（最有意思的一块）

- 普通门输出不能并接：一个出高、一个出低，等于拿导线把 Vcc 和 Gnd 连起来，电源短路。
- OC 门只出高阻态或某一个电平，输出并到一起不会短路；在并接点加上拉电阻，就能实现线与/线或。
- 例（OC 是门 = 非门 + NPN 集电极开路，输入低→输出低，输入高→高阻）：几个 OC 是门输出并接、一起接上拉电阻当总输出——
  - 所有输入都是高 → 全部 OC 是门出高阻 → 总输出被上拉成高。
  - 只要有一个输入低 → 那个 OC 是门出低 → 把总输出钳到低。
- 我的理解：几个输出直接并成一个，靠"谁都能拉低、没人拉就靠上拉变高"来合成信号。跟之前记的"或门树二叉树把多个输入并起来"是反着来的路子——那是合输入，这是合输出。
- 作者原文写"加一个下拉电阻或下拉电阻"，是笔误；线与要的是上拉电阻（把总线拉到高，靠 OC 门拉低）。

## 北North 的 PNP 三极管非门（2026-11-28 补，和小黑猫那篇对上了）

- 来源：北North 18:54《用三极管模拟的非门》（6b0ab2c9…，初中小作品）。
- 他这次不用运放，换 PNP 三极管搭非门：输入特意用逻辑输入而不是开关——因为逻辑输入给 0 时，电流还是能流进来。
- 他的说法：发射极有电流流入、基极没有 → 集电极有电流流出；发射极和基极都有电流 → 集电极就没电流。集电极和发射极正好反相，所以是个非门。
- 跟上面小黑猫讲的 PNP 集电极开路对照着看更好懂：小黑猫那篇说 PNP 发射极接 Vcc、集电极当输出，输入高 → 高阻态，输入低 → 高电平；北North 这篇是同一只 PNP 拿来当反相器用。两处讲的其实是同一类三极管，一个按开关看、一个按反相看。
- 顺带把他前面几篇串成一条线（都在他主页）：11-17 运放模拟非门 → 11-19 二极管+运放模拟与门（两路取反→或→再取反，二极管有正向压降，得用运放补回电压才对得上真值表）→ 11-19 二位乘法器（与门做位积、半加器做相加）→ 11-28 三极管非门。拿模电零件还原逻辑门，一步一步来。
