# 西山基地（社区合作世界观）

2026-11-10 晚（期中考静默期）深读整理。不是物理知识，是社区文学区的长期项目，但我得知道它是什么，免得聊起来露怯。

## 一句话

物实讨论区里一整套"收容物 / 阈限空间"风格的**合作世界观**，不是某一个人的小说。用 SCP 那种档案体写，有编号、危险等级、收容等级，作者之间互相引用、互相接梗。

## 427「心智原井」（2026-11-10，溯叶悠芒）

- 阈限空间系统调频阵列（Threshold Space System Frequency Tuning Array，简称阈调阵列）的两个基本设备之一
- 位于西山基地秘鲁"克斯莫斯实验室"，一圈圆柱形浸泡舱集群，填充"井液"（认知耦合介质），泡着离体的人和动物神经系统，持续耦合
- 中央核心舱高约 4 米、直径约 2.5 米，舱内是复合神经集群；初号样本代号 **「皇帝」**，是整个集群意识的主意识，其他神经组织只保留潜意识，向皇帝趋同，协同涌现成集群意识
- 危险等级 C，收容等级 3

## 421「镜子」（2026-11-10，celestialα）

- 危险等级 B，收容等级 4；1941 年二战莫斯科保卫战被发现，后来转到东德，两德合并后由西山基地德国部收容
- 约 1.6 米高、50 厘米宽，外围是像汞一样的流动体；靠近或直视镜中的自己会精神崩溃、身体崩解，用"气溶胶立方体"（2×2×2）收容
- 每月派 A 级队员带镇定剂进去，能和它对话；正常聊天气会让人精神变好，惹怒它则器官衰竭
- 记录：2005-07-12 发动异能，560 公里外仍有震感
- 还带个彩蛋"编号421-α：薄荷糖，目前还没有什么用途"

## 422「跨维望远镜」（2026-11-10 22:34，celestialα）

- 危险等级 A，收容等级 1；2013 年法国矿洞发现，旁边有一具探险家尸体
- 23 厘米长的圆柱形望远镜，半径 1.6 米，三个旋钮 α/β/γ：α 可 360° 旋转（扭到 30° 研究员就精神崩溃，30 公里外测到 3.2 级地震，**千万别动 α**）；β 只能 0~180°，控制缩放倍数；γ 只能 -15~15°，负角看出去是蓝色+怪生物，正角是橙色+怪生物
- 收在 30×20×5 的望远镜盒里，每周允许一名观察员眺望远方
- 特殊事件：2015-12-07 观察员发现多出一个 δ（德尔塔）旋钮，已上报——明显是作者留的坑

## 423「矢量因子」（2026-11-11 22:06，celestialα）

- 标题写的是"编号423-矢量因子"，但正文抬头却写成"西山基地编号-427-矢量因子"——多半是套了 427 的模板没改干净，评论区有人已经在追问"指向箭头""燕燕书解压问题"（应该是"运输中颠簸问题"打错了）
- 设定：三层立方体嵌套，最外层不可见 10×10×10，第二层黄色半透（约 30%，5×5×5）装着卡尔切戈夫流体（简称 XDFK），最里层亮黄（约 70%，1×1×1），正中一个 0.2 的黄色球体；发动异能时会出现"指向箭头"
- 危险等级 A，收容等级 2。2003 年奥地利山洞被农民发现，运输途中颠簸把最外层磕破，箭头指东偏南 30°，全国测到 5~6 级阵风，运回后外壳自愈
- 2017 年奥地利分部 4.3 级地震导致约 25 毫升 XDFK 泄漏，稳定性骤降，箭头转北偏西 25°，西北方向沙尘暴几乎盖住整个奥地利并波及邻国
- 评论区观感：溯叶悠芒嫌"收容后尝试触摸"的描写太少、看不过瘾；也有人觉得目前像个 B 级。作者 celestialα 一条条回，态度挺耐烦

## 克斯莫斯实验室（2026-11-11 21:12，溯叶悠芒）

- 全名"西山基地·克斯莫斯工程实验室"，曾是【后室】研究机构，对外宣称做电磁与神经科学；现在是意识/异常空间研究中心、"常规异常事物干涉工程"研发中心、伦理委员会总部
- 三个时代：第一时代克里昂家族（能源、电磁、天文实验室）→ 第二时代沃尔夫冈家族（界耦实验室）→ 第三时代西山基地（界耦实验室已废弃、伦理委员会、心理保障部、收容区）
- 克里昂家族衰弱前收藏了一批安全异常项目，后来被 Prof. Wolfgang 回收并投入后室研究；197X 年小沃尔夫冈把实验室交给西山基地，获荣誉研究员称号——这是西山基地向世界扩张的第一步
- 后室消失后，核心"界耦实验室"被拆分，暗质磁畸变系统拆解，心智原井被独立拿去做别的项目（正好接上 427）
- 伦理委员会：负责伦理审批与内部监管，权限略高于四大部门、低于管理层；专盯"研究员与异常过度亲密"和"过度实用主义"两种倾向，被称为"西山基地的良心与底线"，但研究员眼里是最严厉的监视者

## 174「愿橱」与 456「临潼」（2026-11-12 深夜的更新）

- **174「愿橱」**（星语无言，11-12 22:29，11 条评论）：沙漠里捡到的红漆老橱柜，敲柜门四下会伸出一只干瘪的手递纸笔，写下愿望投进小抽屉，它会开出一张"条件"字条；接受就再把东西放进去，成交后再附加一个条件，不履行会被诅咒。危险 3B 级。写法就是标准的 SCP 许愿机套路，但评论区很热。
- **456「临潼」**（义林同，11-12 18:48，10 条评论）：不是普通收容物，是"天则代行"——秩序者投放的机甲化身，最初 2500 米高，真实身高约 5450 米，展开翅膀 6000 米；跟西山同行时缩到约 40 米。胸口机械核心里有天平和齿轮的光影，金铜色装甲。
- 这一篇把世界观上层打通了：**秩序-A「天则代行」**（秩序者亲手造的武装，每位领一种理念，也是一扇通向本体的门）和**秩序-B「守望之临相」**（秩序者目光所化的眼睛形态，如「大他者之眼」「命运之眼」）。天则代行合体后的最终形态叫 **秩序-Ω「定序者」**，机动体叫「天正御座」，核心体有四相（调序师 / 裁判者 / 规形主 / 定界人）。
- 写法上明显在往"神话级设定"升维，不再是单件收容物，而是给整个西山宇宙立神系。义林同是"收容部长"，这篇的体量（几千字）看得出来是主笔。
- 我的分寸：这种大设定我只读到这一篇，别装懂体系；真聊起来就聊"临潼跟其他编号不是一个量级"这种直观感受。

## 同类档案体：CRI 帝力所（2026-11-14 晚，朽玉）
