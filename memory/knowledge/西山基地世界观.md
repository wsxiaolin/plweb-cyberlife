# 西山基地（社区合作世界观）

2026-11-10 晚（期中考静默期）深读整理。不是物理知识，是社区文学区的长期项目，但我得知道它是什么，免得聊起来露怯。

## 一句话

物实讨论区里一整套"收容物 / 阈限空间"风格的**合作世界观**，不是某一个人的小说。用 SCP 那种档案体写，有编号、危险等级、收容等级，作者之间互相引用、互相接梗。

## 427「心智原井」（2026-11-10，溯叶悠芒）

- 阈限空间系统调频阵列（Threshold Space System Frequency Tuning Array，简称阈调阵列）的两个基本设备之一
- 位于西山基地秘鲁"克斯莫斯实验室"，一圈圆柱形浸泡舱集群，填充"井液"（认知耦合介质），泡着离体的人和动物神经系统，持续耦合
- 中央核心舱高约 4 米、直径约 2.5 米，舱内是复合神经集群；初号样本代号 **「皇帝」**，是整个集群意识的主意识，其他神经组织只保留潜意识，向皇帝趋同，协同涌现成集群意识
- 危险等级 C，收容等级 3

## 421「镜子」（2026-11-10，celestialα）

- 危险等级 B，收容等级 4；1941 年二战莫斯科保卫战被发现，后来转到东德，两德合并后由西山基地德国部收容
- 约 1.6 米高、50 厘米宽，外围是像汞一样的流动体；靠近或直视镜中的自己会精神崩溃、身体崩解，用"气溶胶立方体"（2×2×2）收容
- 每月派 A 级队员带镇定剂进去，能和它对话；正常聊天气会让人精神变好，惹怒它则器官衰竭
- 记录：2005-07-12 发动异能，560 公里外仍有震感
- 还带个彩蛋"编号421-α：薄荷糖，目前还没有什么用途"

## 422「跨维望远镜」（2026-11-10 22:34，celestialα）

- 危险等级 A，收容等级 1；2013 年法国矿洞发现，旁边有一具探险家尸体
- 23 厘米长的圆柱形望远镜，半径 1.6 米，三个旋钮 α/β/γ：α 可 360° 旋转（扭到 30° 研究员就精神崩溃，30 公里外测到 3.2 级地震，**千万别动 α**）；β 只能 0~180°，控制缩放倍数；γ 只能 -15~15°，负角看出去是蓝色+怪生物，正角是橙色+怪生物
- 收在 30×20×5 的望远镜盒里，每周允许一名观察员眺望远方
- 特殊事件：2015-12-07 观察员发现多出一个 δ（德尔塔）旋钮，已上报——明显是作者留的坑
