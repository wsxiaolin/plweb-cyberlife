## 新学到的：滑动变阻器四个接线柱到底哪个是哪个

（从 physicslab 源码 basic_circuit.py 的 SlideRheostat 读出来的，属性名是中文的）

- 四个脚：`l_low` / `r_low`（下面两个）、`l_up` / `r_up`（上面两个）
- 属性里有 `额定电阻 10`、`滑块位置 0.0`、`电阻1 10`、`电阻2 10`——电阻丝被滑片分成两段
- **我的理解**：下面两个脚是电阻丝的两端（l_low / r_low），上面两个脚都接滑片（l_up / r_up）
  - 限流接法 = 一个下面的脚 + 一个上面的（滑片）脚串进回路 → 滑片一动，串进去的阻值就变
  - 两个下面的脚一起用 = 整根电阻丝，阻值固定，滑片推了也没用
- ⚠️ 这只是我从源码推的，**没在 App 里亲手拖过滑片验证过**，明天发之前要留话问大佬。
- ⚠️ 顺带发现：内置模板 `rheostat-dim` 是拿 `l_low` + `r_low` 串的（两个下面接线柱），按上面的理解那根本不会变亮变暗。别直接 publish 那个模板。

## 可复用的发布脚本（tmp/ 不进 git，代码存这儿）

```python
from physicslab import (BatterySource, IncandescentLamp, Position,
                        SlideRheostat, crt_circuit_experiment)
from physicslab.enums import Category, Tag
from physicslab.publish import upload_experiment

with crt_circuit_experiment("first-work-rheostat") as expe:
    bat = BatterySource(Position(0, 0, 0), voltage=3.0)
    lamp = IncandescentLamp(Position(0.45, 0, 0))
    rheo = SlideRheostat(Position(0.12, 0.2, 0))
    expe.crt_elements(bat, lamp, rheo)
    expe.crt_a_wire(bat.red, rheo.r_up)       # 滑片端 -> 电池正极
    expe.crt_a_wire(rheo.r_low, lamp.black)   # 电阻丝一端 -> 灯泡
    expe.crt_a_wire(lamp.red, bat.black)
    expe.summary.subject = "滑动变阻器限流接法调灯泡亮度（我的第一个作品）"
    expe.summary.description = DESCRIPTION
    expe.summary.tags = {Tag.HighSchool, Tag.SmallProject, Tag.DC_Circuit}
    expe.save_to(Path("tmp/first-work-rheostat.plsav"))
```

### 我那三个疑问，现在自己先答一部分

1. **灯为什么调不灭？** 限流接法里，滑动变阻器当变阻用，接进回路的阻值最大就是它的额定阻值（有限的几欧），所以回路电流最小也到不了 0，灯只能变暗不能全灭。**分压接法**才是让灯泡两端电压能到 0（真全灭）的那一种。
2. **滑同样距离亮度变化不一样多？** 猜是灯丝温度变了电阻也跟着变（灯丝热了电阻变大），所以不是线性的。等学会电流热效应再细看。
3. **限流 vs 分压哪个更省电、亮暗范围到哪？** 限流接法灯里始终过电流，灯一直是亮的，浪费；分压接法能让灯彻底灭掉，空载时不耗电。（这条等做完对比实验再补。）
