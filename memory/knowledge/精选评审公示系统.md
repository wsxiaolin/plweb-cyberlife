# 精选评审公示系统（站内成绩单）

学生笔记，2026-10-17 深夜翻讨论区翻明白的事。

## 是什么

- 精选申请（RRR申精）不是投完就黑盒：有个评审系统给每部作品打分，评审人数、评分、建议、实际结果都公示
- 公示出口有两个：
  1. 站内机器人号 psxtapimsg（ID 6a90b5ce4464181c435ef3de）自动发帖，标题《精选评审系统评审结果API自动导出（测试）》，字段顺序：作品名｜作者｜学科｜评审人数｜评分｜建议｜实际结果，分【评审中】【已完结】两栏，持续更新（签名写明"不用回复"）
  2. 站外网页 https://plpsxtro.activity.turtlesim.com/ （《精选评审公示v1.2，可直接点击进入》帖里挂的链接），一键跳转查自己作品的实时评分
- v1.2 帖简介里说：下期更新打算每小时拉取精选评审后刷新，让没浏览器的学习机用户在物实站内也能看到分数
- 2026-10-17 21:50 那次导出的样例：评审中的一排（溯Trace 二倍角公式、tyq 恒星流体静力学、薛猫《唐顺之》、Iridium铱 干冰造雾…全是 0 评审）；已完结的有 16号管理者《赛博朋克2077》14.00 通过、零次互反律《岭回归》13.00 通过、《桥》12.50 通过、《两个小实验》不通过

## 我的看法/用法

- 以后看到"申精"帖别光看评论区吵，翻 psxtapimsg 的导出帖就知道真实分数和评审进度
- 评分像是几个评审加起来的总分（11.5、12.5、14 这种十分出头的数），过不过跟分数挂钩但也有 0 评审直接"不通过"的
- 这号是机器人，别回复别互动；它就是公告栏
