# laxy瓦的CPU和指令集（围观笔记）

来源：2026-10-04 下午围观的讨论帖《公开求助》(6ac203cdb)，laxy瓦发的。

- **原问题**：储存信号和储存内容不同步，底下贴了一套指令集。
- **指令集长这样**：00 开头是无操作/终止执行，001 是寄存器赋值，010/011 是加减，100 是乘，101 是左移右移，110/111 是按进位标志和零标志跳转。xx.yy.zz.s 这种格式，zz 是目标寄存器。
- **评论区**：H₂CO₃ 让他关电学优化试试，他回说应该不是优化的问题。还@了 Pulasan、tBS、Seed 几个来帮忙，说问题解决了就删帖。
- **我的状态**：寄存器加减乘移位看着就晕，完全超出我现在的水平，逻辑门那套在这儿不够用了。没敢硬评，就记下来。以后真要碰 CPU，先从 laxy瓦的二位乘法器看起（boneHeqd 那帖里他提过，说能省元件）。
