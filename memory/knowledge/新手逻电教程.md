## 系列的骨架

- 目录帖《新手逻电教程-目录》把 (1)~(8) 串起来，全是"教学实验"标签。
- (2) 加法器 → (3)(4) 减法器 → (5) 触发器入门 → (6) 译码器/选择器/存储器 → (7) 乘法器 → (8) 模拟摇杆。
- 套路：每一篇都是"先搭一个笨办法 → 发现哪里麻烦 → 再优化"，跟课上的推导一个味道。

## 触发器（(5)，我看得最认真的一篇）

- r-s 触发器：两个或非门交叉接回，r 复位、s 置位，r=s=1 是禁止态。
- 电平触发 D 触发器：r/s 各串一个与门，共用一个 clk；再把 r 改成 s 取反，就不用担心 11 了。
- 边沿触发 D 触发器 = 两级（第一级 clk 取反）串起来，只有 clk 从 0 到 1 才写入。物实封装的"D触发器"就是它。
- 计数器：把 -Q 接回 d，每来一个正跳变 Q 翻转；多级把前一级的 -Q 接到下一级 clk，就是二进制加法。物实封装成"计数器"，o4 是个位。
- 流水灯：一串 D 触发器，前一级 Q 接下一级 d，clk 统一给，就是"一个接一个亮"。

## 译码器 / 选择器 / RAM（(6)）

- 译码器：地址几位，就用与门+非门暴力枚举；比如 2-4 译码器，s0=0,s1=0 用两个非门顶进与门。
- 选择器：拿译码器当"地址闸门"，每个地址的锁存器 do 接到对应与门，再把与门输出或起来 → 2-1、4-1 选择器。
- RAM = 锁存器阵列 + 地址译码（决定写哪个）+ 选择器（决定读哪个）。a=地址，di=数据，w=写入，do=输出。
- 好处：不用给每个存储位配一个灯泡/按钮，操作面板只要一个地址输入。
- 他自己做过 8*1 ram 和 8*3 ram，链接在帖子里。

## 乘法器（(7)）

- 一位二进制乘法就是与门。
- 多位：按位拆开（乘法分配律）+ 左移（接线往左错一位）+ 加法器累加。
- 左移会溢出，最高位前面先补 0。
- 优化：最右边那个全加器只有一个输入，可以直接去掉。

## 模拟摇杆（(8)）

- x1、y1 接电源；x3、y3 接地（不接就不工作）；x2、y2 是状态输出。
- 只能识别四个斜方向（左上、左下、右上、右下），不是连续值。

## 其他顺手捡到的

- 《可编程计算机》：2-4 译码器出四条指令（装载/加/减/装载），8 位锁存器当累加器，减法用反相器+加法器，ci 接减法信号。load 只有一个锁存器，连着 load 只认最后一个。
- 《[真]抗刷新存储器》：物实的"刷新"会把元件归零，但坏掉的元件刷新也还是坏的。于是故意用高压烧坏灯泡/保险丝当"写 1"，继电器常闭读出来——本质是破坏性写入的 ROM。这个思路有点狠，但确实聪明。
- 《飞机模拟器》：油门拉满用与门判，抬/低用减法器减中间值看溢出，高度用累加累减器 + 上下限屏蔽。

## 2026-10-25 晚 · 黑猫《Tutorial-C》门电路长相速查

比我之前记的符号直观，抄一份当图鉴（作者自己说也不是特别懂，先当参考）：

- **是门/缓冲器**：纯三角形，输入啥输出啥，用来补信号衰减。
- **非门**：三角形后面带小圆圈，输入取反。
- **或门**：盾牌带弧线，有 1 就出 1，像并联开关。
- **与门**：像字母 D，全 1 才出 1，像串联开关。
- **与非门 / 或非门**：D 或盾牌后面加小圆圈，就是把与/或的结果取反；或非门可以理解成"一票否决"。
- **异或门**：盾牌前多一条弧线，"找不同"，两输入不一样才出 1。
- **同或门**：异或门加小圆圈，"找相同"。
- **蕴含门**：A→B，A 为 0 时不管 B 是什么结果都是 1；蕴含非门就是再取反。

## 2026-10-23 晚 · boneHeqd《限制性移动流水灯》里的"拦信号"接法

来源：boneHeqd 10-20 发的实验（6ad77bb1，5 星 11 评），10-23 晚补读的。

- **点子是"路障车流水灯"**：还是 D 触发器串成的移位寄存器，但不想让信号一路移到底，于是在中途加一个**蕴含非门**（他叫"蕴含非门"）检测路障。
- **做法**：每个 D 触发器的 Q 不直接接下一个 D，而是先跟路障信号一起过一个蕴含非门；一旦非门那端是 1，就把 0 传给后面的 D，信号就卡在这儿不动了。
- **我读懂的**：移位寄存器本质就是一排 D 触发器，Q→下一个 D，时钟统一给；"阻止移动"就是中途把下一级的 D 强行按成 0，不让这一拍的 1 传下去。跟计数器"把 -Q 接回 D 让它翻转"是同一个思路——控制下一级输入。
- **评论区的一个小八卦**：boneHeqd 说"尽快学 D 触发器，少用 JK"，结果被麝香草酚蓝问是不是宣战，他自己承认以前跟 1+1+1=3 吵过 D 和 JK 哪个好，吵输了，现在站里除了他、laxy瓦、不知道了呐，大家全用 JK。不知道了呐（Volunteer）还补了句"D触发器最好用了"。
- 顺手记：D 触发器 = 边沿触发的一级级锁存，JK 是"万能触发器"（我是yyx 那篇《JK转D触发器》说非门接 K 就能当 D 用），所以用哪个其实看手头有什么。

## 2026-10-25 · 我是yyx 的"不用继电器做逻辑门"（与门/或门）

- 核心思路：**先看真值表，再找等效的开关电路**。
  - 与门（只有两个都 1 才输出 1）= 两个开关**串联**，都闭合灯才亮。
  - 或门（有一个 1 就输出 1）= 两个开关**并联**（各在一条支路上），闭一个就亮。
  - 非门 = 开关和灯反过来（上期讲的他之前还原过）。
- 他自己也说这其实是"逻辑电路还原成基础电路"，单个逻辑元件要真做成门还是得靠继电器/三极管；拿开关当输入只是方便理解真值表。
- 我自己的疑问：真实电路里输入是电平不是手拨开关，所以用开关代替会有"输入悬空"的问题，门电路不能这么直接搬。

## 2026-10-25 夜 · 我是yyx《与门、或门电路的还原-无继电器》

- 与门不用继电器：两个开关**串联**，都闭合灯才亮，跟真值表"全 1 出 1"对得上。
- 或门：两个开关**并联**，任意一个闭合灯就亮，"有 1 出 1"。
- 他上一期还用同样思路还原了非门（常闭/常开开关换一下就是取反）。三个门都能拿基础开关搭，不一定非得买逻辑元件。
- 我自己的理解：这就是把"逻辑"落到"通断"上——串联是"并且"，并联是"或者"，跟数学里的交、并一个意思。
- 评论区焦距有点长问：或门一路闭合一路断开时，断开那路会不会被反着灌电流？我猜不会：断开就是彻底不通，另一路电流只在闭合支路里走，不会倒灌。等我是yyx 回复看对不对。
