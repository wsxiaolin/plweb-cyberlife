# 游戏/计数器里的小元件（偷师笔记）

来源：杜Du《制作游戏教程》(6ab2646ec803aa02d5f7a095)，2026-09-26 看。Ryyan《让显示器显示到255》也用到了同一套。

- **D 触发器流水灯**：最后一个触发器的 -Q 端接回第一个的 D 端，就一直滚。扩建时前面的几个别动，从第四个开始照抄第三个的格式。
- **锁存器**（我一直没搞懂的那个）：拿或门，把输出端接回它自己的一路输入，只要进一次信号就一直保持。除非把整个元件删掉或拆线，否则数据清不掉。—— 可以当"模式选择"按钮用。
- **可显示计数器**：CLK 和 R 同时给信号就清零；按一下 +1。用在游戏积分板上很合适。代价是加了按钮开关以后电路不算纯数字电路，会掉效率。
- **八位输入移动器**：拖数字就移动角色。缺点是移动途中还要按按钮的话，得再点一次元件才继续控制。
- **计数器级联到 255**：单个计数器到 15，所以 Q1Q2Q3Q4 全 1 的时候要进位到第二个计数器。用"先保存数据、等全 0 时再进位同时清保存"这套来做（Ryyan 的做法）。
- **半加器**可以用来判当前是红灯还是绿灯这种二选一（Ryyan 做红绿灯用的）。

我的疑问：全 0 时进位这一步到底怎么"保存"数据？是用锁存器把四个 Q 的状态存下来，再用非门全检测 0 吗？下次试的时候自己接一遍。

## 追加：2026-09-26 又偷了两个师

**Ryyan《让显示器显示到255》评论区**——张金行给了答案：「其实第 2 个计数器为下降沿触发就能解决问题」。
所以根本不用自己存数据，把第二个计数器的 CLK 触发沿改成下降沿，进位就自然对齐了。我绕了一大圈的思路人家一句话就完了。

**杜Du《RRR申精「躲避疯牛」》(6ab10cf7a)**——游戏里的几个阴招：

- **随机移动**：JK 触发器流水灯 + 非门 + 两个计数器 + **随机数发生器**。牛不是匀速跑的，是每帧随机的。
- **继电器做"模式选择"**：拿一个继电器，一端接地元件，另一端用逻辑输出驱动，黑色接线柱接 CLK 端，另外两个脚分别接上一个计数器的 O3、O4——就能控制这个计数器走不走，等于给速度加了档。（教程里说的"锁存器"和这个思路是同一类东西：让数据保持住。）
- **输赢判定**：用或门把"被撞到"的条件锁存住，然后接一颗**额定电压调到 0.1V 的白炽灯泡**——一通电就炸，用来表示失败。炸灯比点灯带劲。
- **Y 坐标判定**：玩家 Y 在 2~5 之间时用或门框出来，再串 16 个与门分别判断 X，才知道撞没撞上。
- 排行榜赏金是他自己发的支持（不是求支持，是悬赏通关）。
