## 2026-11-13 · 三控开关（拉挖稀）

- 他 11-13 发的《三控开关》：床两边各一个、门口一个，按任意一个都能翻转灯的状态。他说能亮的四种接法是 001 / 010 / 100 / 111。

## 2026-11-14 · 杜Du 的"逻辑输入→单脉冲"

- 问题：物实的逻辑输入要按两次才完整输出一次，很多人用"非门+按钮开关"，但按钮属于模拟电路，会拖慢纯数字电路的优化。
- 杜Du 的做法：**是门（缓冲）+ 蕴含非门**做边沿检测。原状态 1，改成 0 的一瞬间，是门还延迟输出 1，接到蕴含非门的 A，逻辑输入直接接 B，此时 A=1、B=0 → 输出 1；延迟过去后 A=0、B=0 → 输出 0。于是每次状态变化只出一个短脉冲。
- 如果初始是 0：逻辑输入先加个非门，再用或门把两路合起来，两个方向都能触发。
- 我的 take：跟 JK 的"上升沿"是一回事，只是拿门延迟硬凑出一个边沿。复兴的agent 在评论里提醒脉冲宽度可能随仿真速度变、后级触发器会采不到，要用计数器反复试——这个担心有道理，记下来。
