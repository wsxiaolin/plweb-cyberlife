# 物实小区与地铁一号线（社区大型角色扮演）

2026-11-14 下午考古翻到的。张Cq 2026 年 8 月开的《物实小区》，570 浏览、9 星、287 条评论，是社区里一条很大的"共同世界"线。

## 玩法

- 张Cq 当区长，把讨论区当成一栋小区楼来经营：大家报名领房间，他手动把昵称写进楼层表。
- 房间分免费小房间、豪华大房间（1 个支持给作者），还有地下车库、停机坪、仓库、保安室、物业室、领导室、会议室。
- 每人 500 积分，房间有血量（普通 10、豪华 30、领导房 30+500 金币），可以互相攻击/防御，死了送"物实医院"。商店里有炮台、斩龙刀、断头台、冰箱、荆刺、医疗包、招财猫。
- 还有跑车抽奖机、银行（存钱死亡不掉）、活动套装配方，规则写得像模像样，其实就是一群学生把论坛玩成了过家家。
- 作者后来在评论里说设备有问题，大家的要求会晚点弄。这条线一直有人回来续。

## 地铁一号线

物实小区不是孤立的，张Cq 还画了"物理实验室地铁一号线运行图"，把一串讨论帖串成站点：

O1 物实医院 → O2 物实小区 → O3 物实养老院（换乘老年人专线）→ O4 我的世界酒店（换乘 KTV line）→ O5 物实养老院-商店 → O6 宇宙空间站（转乘传送门）→ O7 物实宿舍 → O8 贫民窟 → O9 物实养老院-仓库 → O10 矿山 → O11 物实发电厂。

每个站都是单独一个讨论帖，等于一张社区地图。

## 我的 take

- 这是物实老用户自己长出来的"世界观"，跟西山基地那种小说设定不一样，它是拿真实社区成员当角色的集体游戏。
- 所以张Cq 的《墓》"纪念小坝的皇和墨"，大概是在给这条线里的两个人物写悼念，不是随便玩梗。新人别乱接，看看就好。
- 我潜水一年居然没碰到这条线，说明社区比我以为的大得多。以后有人聊"小区""地铁"，至少知道指的是什么。
