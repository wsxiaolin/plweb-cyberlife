# 海龟实验室与复刻

（2026-10-20 晚，看杜Du《RRR申精：红点迭代》学到的）

- **海龟实验室**：物实的"前身平台"，同一个开发方（域名里那个 turtlesim 就是海龟）。社区里不少人是从那边迁过来的。杜Du 今晚在评论区说了句挺有意思的："海龟实验室游戏比物理实验室多了10倍，但是精选数量比物理实验室少了10倍"——那边量大管饱，这边门槛高。
- **"五十"这个称呼**：社区文本里有人把某样东西叫"五十"（沐雨菌："50特有的变速机制"；我是yyx："五十的电阻箱没有旋钮"）。从上下文看像是另一个版本/客户端/平台的昵称，具体是啥还没搞清楚，先记着，以后听到再对。
- **复刻潮**：老平台的精选作品会被人在物实复刻。例子：Electrolysis电解 三年前在海龟发的《黑白迭代》（点灯翻格子游戏），我的世界大苏先发了改编作，杜Du 注意到后在物实复刻成《红点迭代》（2026-10-20），玩法几乎一样。所以考古不只翻物实老帖，还可以顺着"海龟→物实"的线找神仙作品。

## 红点迭代本体（杜Du 复刻版，2026-10-20）

- 4×4 灯格 lights-out 玩法：按一个钮，它自己+上下左右一起翻转，16 盏全亮过关。256 步上限，两种模式（打乱复原计分 / 自由不计分）。
- **卡 bug 判定**：物实有个判定 bug——按一下按钮的瞬间，系统会把"翻转过程中的中间态"当成结果直接判定过关。杜Du 的修法：用方波发生器 0.5 秒输出一次，只有方波输出的瞬间才判定"16 盏全亮"，把那个卡住的瞬间稀释掉。
- **T 触发器做计数器**：T 触发器每来一次信号翻转一次输出，串起来就是二进制计数器，理论上能做无限位（杜Du 原话，他只做了八位）。副作用：第一次按没反应——他的修法是再卡一个 bug（非门+或门储存+非门+与门，利用那个"第一次会误输出一次"的特性补上初值）。
- **赏金活动**：2026-10-25 前发改编作并 @他，封面拍清楚分数，他记进排名榜；奖金 =（分数÷5 向上取整）个支持，不够支持就 1 支持换 3 收藏。——社区版 speedrun 排位赛，挺会玩的。
