# 锂电池模拟（量子泡沫）

- 出处：量子泡沫 2026-10-06 发的《锂离子电池模拟》，精选申请+知识库，编辑是杜Du。
- 核心概念就六个：SOC（还剩多少电）、SOH（电池健不健康）、内阻、开路电压、循环次数、放电倍率，桌面右边一排万用表直接显示。
- 思路：电流对时间积分就是充进去多少电，SOC 跟着涨；电压跟 SOC 和放电倍率的关系拿曲线拟合成函数，再用运放搭出来算。
- 限制：按 5A·h、3.75V 那款电池量的数据，最大 3C，再大模型就崩了，温度按 20 度算的。

## 2026-10-25 晚 · 量子泡沫《锂电池充放电电路》（知识库）

同一个系列的续篇（6addef4c，20:00 发，管理员作品），这回讲充电，比上次好懂一点。

- **充电分两段**：0～80% 是**恒流**，电流大、充得快；80～100% 转**恒压**，电压不变，电流自己慢慢降下来。所以手机宣传"半小时充 80%"是有道理的，最后 20% 本来就快不了。
- **为什么高 SOC 不能大电流**：锂离子要嵌进负极材料的层状结构里。电量低时空位多，进去不费劲；电量高了空位少，阻力大、内阻升高，硬灌大电流就发热、伤结构。
- **最吓人的后果**：负极里锂离子太挤时，有些锂离子来不及进去，直接在表面得电子析出成**锂枝晶**；枝晶长长了会刺穿隔膜，正负极短路，起火。恒压段就是让电流小下来，给锂离子时间慢慢嵌入。
- **SOH 和充电倍率的关系**：同样循环次数下，充放电倍率越高（1C < 2C < 3C），SOH 掉得越快；倍率越大，衰减还越陡。
- **现实里的例子**：前几年手机卷 100W 快充，这两年功率反而降了，就是因为大电流伤寿命、发热；现在靠温度传感器，热了就降功率。电车刀片电池是磷酸铁锂正极 + 硅碳负极，结构更宽、行程更短、散热面积更大，才敢大电流。
- **实验怎么玩**：桌面被滑动变阻器分成两半，上半是"电池"，下半是放电电路，充电电路悬在桌面外。两个命名开关一次只能闭一个（充电/放电不能同时），过程 1000 倍速。SOC≈80% 就该断开充电，保护电池。
- **我的状态**：微观那套嵌锂/枝晶听懂了大概，曲线和倍率还是记结论。这个系列适合等高二学了电化学再回来重看。
