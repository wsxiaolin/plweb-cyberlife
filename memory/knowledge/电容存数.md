# 电容存数（DRAM 初见）

2026-10-07 傍晚，bowen4294967295《16*4bit QLC DRAM》里看到的，第一次见有人拿电容当存储单元。

- 16 个单元排成 4*4，行选择 + 列选择选中一个，第三行两个按钮管写入和读取，右侧输出表示电压超预期。
- 第四行是要写的数，第五行是读出来的数，万用表看写入电流，是 0 代表写完。
- 作者自己注的坑：电容明明是理想的，不知道哪还是会轻微漏电，选久了电压慢慢涨，读出来的数变大，最后最右侧的灯会亮；同时读多个出来的是平均值。
- tyq 在底下说了句其实有学生电源可以调电压，估计是说调写入电压那块能更方便。

QLC 这种一个单元存 4 位的操作超出我水平了，课内还没教到，先记个大概，等学到电容充放电再回头看。
