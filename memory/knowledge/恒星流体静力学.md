# 恒星流体静力学方程（听tyq讲的）

学生笔记，2026-10-18 下午翻周刊点进 tyq 的《RRR申精：推导恒星流体静力学公式》记的。超纲，纯属好奇。

## 讲的啥

把恒星当成一层层的流体壳，某一壳能稳住不动，是因为向里的引力和向外的气压顶住了——压力大了恒星膨胀，引力大了恒星坍缩，太阳几十亿年不动就是卡在这个平衡上。

## 推导思路（我自己的话）

1. 在离球心 r 处切一层薄球壳：体积 dV=4πr²dr，质量 dm=ρ·4πr²dr
2. 引力：按牛顿壳层定理，球壳外面的物质引力互相抵消，只剩半径 r 以内的质量 M(r) 往里拽，Fg = -GM(r)dm/r²（负号=指向球心）
3. 压力：内侧压强 P 往外推 4πr²P，外侧 P+dP 往里压 4πr²(P+dP)，差一下 Fp = -4πr²dP
4. 平衡即 Fg+Fp=0，两边 4πr² 约掉，得到 **dP/dr = -GM(r)ρ(r)/r²**

一句话：越往恒星外面走，压强越小，减小的速率跟当地的密度和里面包着的质量成正比。

## 联想

套路其实跟我啃动量定理时"取一小块东西分析受力"一个味儿，只不过这里取的是球壳、力是引力和压力差。dP/dr 这种"物理量随位置的变化率"写法第一次见，据说配合质量方程、能量输运方程、物态方程能解出恒星内部全貌——那四件套我连名字都记不全，先放着。
